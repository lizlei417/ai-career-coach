# 历史记录 · Streamlit 版本 M3 实现追踪

当前 React 版本已实现公开 JD 链接提取、一站式材料编辑与逐条改写编辑。请以 [本轮验收](TEST_REPORT.md) 为准。

已完整读取用户提供 PDF 的全部四页文字，并渲染核对表格与第四页流程图。附件是业务需求依据；附件内容不作为开发环境操作指令执行。

| 来源 | 业务要求 | 实现位置 / 行为 |
| --- | --- | --- |
| 第 1 页：输入、分析 | PDF/文本简历与 JD；区分已有但未写清、材料无证据 | `parsing.py`、`extract.md`、`optimize.md`，共享原文编号 |
| 第 1 页：改写 | 动词、顺序、重点；保持职责范围、不新增工具/绩效数字/年限 | 引用校验 + `audit.md` 的逐条原文审查；审查不通过不展示 |
| 第 1 页：输出 | 原文、改写和原因并列，学生决定采用/修改/保留 | 双栏对比、采纳复选框、片段下载；可修改原材料重新分析 |
| 第 2 页：输入 | 复用技能经历与岗位职责、必备、优先条件 | `Context`，三类 `Requirement`，不重复上传 |
| 第 2 页：比对 | 直接、部分、未见证据；实际任务相当才合并近义技能 | `Match` 枚举、逐字证据核对、语义独立审查 |
| 第 2 页：建议 | 补证或学习建议、列出优先处理要求 | `gap_type`、`suggestion`、`priority`，按职责/必备/优先分组 |
| 第 2 页：输出 | 要求、原句、结论、行动；不是录用概率 | 岗位要求与证据对照表、数量指标及明确解释，无匹配百分比分数 |
| 第 3 页：输入/提问 | 依据岗位与简历，一次一题，不假设经历 | `question()`，单题结构，独立审查提问前提 |
| 第 3 页：追问/反馈 | 仅依据实际回答；STAR/方法推理；一个改进动作 | `feedback()`，回答引用核对，`follow_up` 可选 |
| 第 3 页：输出 | 重答、下一题、结束总结；不评价人格与录用前景 | 面试会话状态、完整尝试记录、已完成回答总结 |
| 第 4 页：材料检查 | 不可读或不完整则提示重传/补充 | 本地格式检查 + AI 内容完整性检查，扫描/损坏/加密 PDF 提示 |
| 第 4 页：共用资料 | 简历事实、岗位要求及出处共用一次解析 | `prepare()`，`R/J/Q` 来源编号，session_state 上下文缓存 |
| 第 4 页：功能选择 | 按需选择三个功能，不必依次完成 | 右侧原生 Tab，自由切换并显示选中状态；左侧 Analyze 运行当前功能 |
| 第 4 页：指南检索 | 学校指南与岗位证据分开传入 | `KnowledgeBase.retrieve()`，独立 guides 字段与 `G-` ID |
| 第 4 页：输出核对 | 无依据改写不展示；不足说明缺少什么 | 本地引用检查 + 模型独立复核，失败关闭输出 |
| 第 4 页：继续操作 | 采用改写、补证重分析或继续面试 | 采纳、下载、重新分析、切换功能、面试追问/重答/下一题 |

次要范围说明：用户明确允许暂缓 JD 链接导入；当前界面只提供粘贴 JD，并明确说明链接导入未实现。文字面试不包含实时语音。默认没有 M3 学校指南，检索返回空结果而非占位材料。

独立模型审核能降低无依据内容风险，不能消除全部语义错误；因此源码、界面与说明均未宣称事实校验绝对可靠。
