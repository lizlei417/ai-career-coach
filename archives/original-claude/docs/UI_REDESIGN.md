## 三语行为

默认 English，支持简体中文与繁體中文。115 个界面文案键均有三语版本，27 个静态后端错误和动态材料/指南错误在 UI 边界本地化。Streamlit 原生上传控件没有语言参数，因此使用窄范围的 CSS/DOM 适配本地化按钮可见文本、可访问名称及原生文件错误；不读取或修改用户材料、输入值、答案或模型内容。

界面语言不再参与材料指纹，因此切换语言保留共享上下文、原始简历/JD、分析结果、采纳选择、回答草稿和面试历史。新生成遵循当前语言；已有输出保留其原语言，并提供主动重新生成简历优化、匹配或面试总结的操作。新语言生成会替换相应结果，面试总结重新生成不会删除已完成问答。

简历、JD、模型及 Prompt 的变化仍按原规则使旧分析失效；新增兼容旧版语言指纹的迁移，材料一致时不因 UI 升级额外丢弃已有结果。

## 请求状态

- 未连接：没有密钥。
- 连接待验证：已配置密钥，本次会话尚无完成的模型请求。
- 上次请求成功：由实际模型请求成功返回设置，不声称实时连接正常。
- 请求失败：最近请求发生错误。

更换密钥或模型会重置验证状态。`ObservedClient` 只观察已有生成请求的返回与错误，不额外发送探测请求，不改变 SDK 参数或生成流程。
