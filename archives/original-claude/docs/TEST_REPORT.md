# React 工作台验收记录

2026-11-20，香港。验收环境为 macOS、Python 3.12、Vite 生产构建和本机 Google Chrome 157。

## 实际运行

| 项目 | 检查结果 |
| --- | --- |
| 启动与构建 | TypeScript 检查与 Vite 构建通过。FastAPI 提供网页、建筑图和同源 API。Python 依赖检查通过。 |
| 首页与工作台 | 点击「开始使用」直接显示简历、JD 和三个功能标签。浏览器确认没有向导元素；在当前页上传文字 PDF、粘贴正文、切换标签、启动分析和查看结果。支持方向键、Home、End 切换标签。 |
| 公开 JD | 实际导入 Figma 在 Greenhouse 发布的 Account Executive 岗位，读取正式岗位页，提取 6,999 个字符。测试断言检查导入文本及工作区内原文。页内容随发布方更新。 |
| 导入失败 | 私有地址被拒绝。单元测试覆盖非 HTTP 地址、异常端口、无岗位正文、HTML 正文与 JSON-LD JobPosting。每次重定向重新检查目标地址。 |
| 无密钥 | 实际服务报告模型未连接。三个 AI 操作均禁用，原文仍可浏览。三种语言、三个功能间切换均保留输入。清空工作台后回到欢迎页。 |
| 简历优化 | 独立测试服务验证多建议切换、原文定位、指南引用、采用、手动修改、保留、语言切换与重新分析。底层测试覆盖错误引用、凭空增加数字和审核未通过时的拦截。 |
| 岗位匹配 | 同一项目直接进入匹配。浏览器展示三类证据状态、优先项、JD 原文、判断与补证建议，可展开细项。 |
| 模拟面试 | 提交回答、重答、追问、下一题与结束总结全部走通。切换模块保留草稿，刷新页面恢复已提交记录和总结。 |
| 共用资料及 RAG | 在同一项目完成三个功能及重新生成后，模型材料提取次数仍为一次。更改简历后旧分析和面试立即隐藏，还原原文可再次查看；重新分析新材料后提取次数为二，新一轮的后续功能复用第二份资料。用临时指南文件实际执行检索，并在结果中查看文件名。默认交付目录载入零篇学校指南。 |
| 三语 | 英语、简体和繁体界面切换，保留原始输入、既有结果和已做的改写选择。测试核对了请求的输出语言和已保存结果的语言提示。 |
| 浏览器与回归 | 50 项 pytest 测试通过，含旧 Python 服务回归、API、校验及新前端浏览器流程。浏览器测试没有捕获页面脚本错误。Starlette 的测试客户端报告一条 httpx 适配器弃用提示。 |
