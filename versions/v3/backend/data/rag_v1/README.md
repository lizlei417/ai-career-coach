# CityUHK 求職輔導原始知識庫 v1

採集日期：2026-11-21。本版只保存可直接取得並核驗的官方 HTML。這是原始語料層，不是向量服務。未連接外部模型，未納入學生簡歷、測試個案、外部書籍或影片正文。快照僅供專案內核對，非再發佈授權。

|功能|來源及片段數|可支持的回答|
|---|---|---|
|簡歷優化|圖書館 Resume & CV writing，5 段|指出校方列出哪些履歷資源。不能據此產生「校方規定」的改寫規則。|
|崗位匹配|圖書館 Career Exploration，7 段|提出查找行業與技能資料的途徑；不提供具體 JD、匹配分數或錄用概率。|
|模擬面試|圖書館 Interviewing & Presentations，4 段；電子工程學系 2019 年活動回顧，2 段|查找準備資源；可引述工作坊曾介紹 STAR 或安排同儕回饋。活動報道不是現行評分標準。|

## 原型如何使用
逐行讀取 `chunks.jsonl`。先按 `function` 篩選，再按問題和 `evidence_type` 選取；`text` 是官網文字（僅規整空白及 HTML 標籤）。介面顯示 `page_title`、`section`、`source_url`。`chunk_id` 用於記錄檢索結果；`sources.json` 給出來源、擷取時間、原始檔位置和 SHA-256。

`resource_listing_only` 只能回答「校方列出甚麼資源」；`listed_resource_url` 是被列出的目的地，不代表已讀取。`library_context` 是圖書館的導覽文字；`historical_workshop_report` 只支持對該次活動的描述。若無相應證據，回覆「目前收錄的校方資料不足以回答」，不要用模型補寫。學生經歷以本人簡歷或補充材料為準；崗位要求以該份 JD 為準。

## 範圍缺口
商學院 CV、LinkedIn 和 Prepare Interview 候選網址在本次直接下載時回傳 404，未以搜尋摘要或第三方快取替代。未取得校方逐條履歷改寫手冊、特定崗位能力矩陣或正式面試評分表。登入、受限資料和外部全文不在本次範圍。

## 離線驗證
在本目錄執行 `python verify.py`（依賴 beautifulsoup4，不需連網）。讀取 `raw/` 原始快照而非重新下載，核對兩級 SHA-256、官方來源、片段原文與來源數量。
